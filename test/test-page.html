Página de Demonstração — MaxVideo Pro

Use esta página para testar os recursos da extensão localmente.

Como testar agora mesmo:

  • Baixar Vídeo: Pressione Alt + D ou clique no botão de download (📥) na barra flutuante ou no menu da extensão para salvar o arquivo de vídeo diretamente no seu computador!
  • Modo Janela Limpa (Sem abas, URL ou favoritos): Pressione Alt + W ou clique no botão roxo do menu da extensão. Observe que o vídeo abrirá em uma janela desktop sem barras do navegador! Pressione Alt + W novamente para retornar à aba original.
  • Maximizar na Janela (Viewport Fill): Pressione Alt + M ou passe o mouse sobre o vídeo para ver os botões rápidos no canto superior direito.
  • Tela Cheia Imersiva: Pressione Alt + F.
  • Picture-in-Picture: Pressione Alt + P.
  • Zoom / Cortar Barras Pretas: Pressione Alt + Z repetidamente para alternar os modos de proporção.
  • Velocidade: Pressione [ para desacelerar e ] para acelerar.
